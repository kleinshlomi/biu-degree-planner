# מסלולון BIU

כלי תכנון עצמאי לתוכניות לימוד ולמערכת שעות באוניברסיטת בר־אילן.

## מה יש באתר

- 34 תבניות למסלולים נפוצים
- התאמה לחד־חוגי ולדו־חוגי
- מחשבון חובות עולמות, אנגלית וקורסים כלליים
- צילום מלא של קטלוג תשפ״ז עם 10,878 שורות שנאספו מן האתר הציבורי
- בחירת הרצאה, תרגיל, מעבדה ושאר יחידות השיבוץ
- זיהוי חפיפות ומנוע המלצה לפי ימים, שעות, חלונות ומספר ימי לימוד

## אמינות הנתונים

האתר הוא כלי תכנון ואינו מחליף את אינ־בר, שנתון המחלקה או אישור אישי.
באיסוף החוזר נשמרו כל 10,878 השורות שהציג קטלוג תשפ״ז. מידע חסר בשדה
מסוים משקף מידע שלא פורסם בקטלוג, ולכן עדיין נדרש אימות באתר הרשמי.
